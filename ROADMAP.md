# Roadmap

Where Mischief is headed. This is the public, sanitized roadmap — see `docs/` for technical details.

## Phase 1 — Foundation (current)

- [x] Repository structure, governance, community files
- [x] Electron + TypeScript skeleton with overlay companion + tray
- [x] CI, tests, linting foundation
- [ ] Runtime lifecycle and event system
- [ ] Scheduler and configuration system
- [ ] First official Experience Packs

## Phase 2 — Runtime & Experiences

- [ ] Deterministic event scheduler (priority, conditions, cooldowns)
- [ ] Experience Pack framework (declarative content)
- [ ] Character system, animation engine, audio engine
- [ ] Plugin SDK + sandboxed plugin host
- [ ] Settings UI, Experience Browser

## Phase 3 — Ecosystem

- [ ] Themes, localization, profiles
- [ ] Diagnostics and crash recovery
- [ ] Community pack/plugin submission
- [ ] Marketplace preparation

## Phase 4 — Release

- [ ] Official experiences + characters
- [ ] Installers for Windows, macOS, Linux
- [ ] Documentation suite
- [ ] v1.0 public release

## Beyond 1.0

- Marketplace and creator tools
- Optional cloud sync (opt-in)
- Community ecosystem expansion

We build in the open — [issues](https://github.com/moiz-za/Mischief/issues) and [discussions](https://github.com/moiz-za/Mischief/discussions) drive what comes next.
