# Kumo the Cyber Fox ⚡

Kumo is a cyberpunk neon Kitsune for developers, tech lovers, and dark-theme desktop power users.

## Character Overview

- **Species:** Cyber Fox (`cyber-fox`)
- **Personality:** `curious`
- **Category:** Tech
- **Unique Behavior:** Features neon cyan particle glow, glitch-pounce reactions, and low-battery standby power node mode.

## Supported Animations

- `idle`: Neon tail waggle & visor pulse
- `walk`: Cyber stride across screen
- `run`: Glitch pounce / sprint
- `happy`: Cyberpunk wag & visor smile
- `sad`: Drooping cyber ears & dimming LEDs
- `sleep`: Standby power node mode
- `yawn`: System reboot stretch
