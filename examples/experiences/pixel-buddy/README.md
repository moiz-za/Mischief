# Pixel Buddy

A pixel-art blob that bobs and blinks. This pack demonstrates **animated GIF
sprites**: the overlay renders the GIF directly in an `<img>` tag, so the
animation plays for free while the CSS bob/sway/sleep effects still apply.

- **Manifest:** `manifest.json`
- **Character:** `characters/pixel.json` (Pixel, species `pixel`)
- **Sprite:** `images/buddy.gif` (80×80, transparent background, looping)
