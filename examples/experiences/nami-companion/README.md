# Nami the Wave Otter 🌊

Nami is a cheerful sea otter floating on an ocean wave across the bottom of your desktop screen, juggling sea pebbles and swimming along window bottoms.

## Character Overview

- **Species:** Sea Otter (`sea-otter`)
- **Personality:** `friendly`
- **Category:** Chill
- **Unique Behavior:** Features a wave-float drift, sea pebble juggling, and swimming strolls.

## Supported Animations

- `idle`: Wave float & pebble hold
- `walk`: Paddle swim across desktop bottom
- `run`: Water-slide dash
- `happy`: Pebble juggling celebration
- `sad`: Drooping whiskers & wave sink
- `sleep`: Sea kelp wrap sleeping mode
- `yawn`: Otter stretch & splash
