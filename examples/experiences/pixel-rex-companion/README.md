# Pixel-Rex the Retro Dino 🦖

Pixel-Rex is an 8-bit retro T-Rex desktop pet that stomps across window tops and plays desk-jump obstacle mini games during breaks.

## Character Overview
- **Species:** Pixel Dino (`pixel-dino`)
- **Personality:** `energetic`
- **Category:** Retro
- **Unique Behavior:** Features 8-bit stomping strides, tiny T-rex arm dances, and desk-jump obstacle mini-games.

## Supported Animations
- `idle`: 8-bit tail thumping & eye blink
- `walk`: Pixel stomp across window tops
- `run`: Dino obstacle sprint
- `happy`: Tiny-arm rawr dance
- `sad`: Teardrop pixel idle
- `sleep`: Curled egg shell sleeping mode
- `yawn`: Big roar yawn
