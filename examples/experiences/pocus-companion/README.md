# Pocus the Ghostling 👻

Pocus is a translucent cozy ghostling that plays peek-a-boo behind open app windows.

## Character Overview

- **Species:** Ghost (`ghost`)
- **Personality:** `mischievous`
- **Category:** Spooky
- **Unique Behavior:** Features semi-transparent floating sheet translucency, peek-a-boo window hiding, and candle flame flickering.

## Supported Animations

- `idle`: Translucent floating & sheet wave
- `walk`: Ghostly float across screen
- `run`: Spectral dash / rush
- `happy`: Peek-a-boo pop celebration
- `sad`: Fading translucent glow
- `sleep`: Soft puff cloud nap
- `yawn`: Candle flick yawn
