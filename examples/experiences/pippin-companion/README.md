# Pippin the Wobbly Penguin 🐧

Pippin is a wobbly penguin desktop pet that slides on its belly across window edges and taskbars.

## Character Overview

- **Species:** Penguin (`penguin`)
- **Personality:** `energetic`
- **Category:** Fun
- **Unique Behavior:** Features a waddling stride, snowball toss reactions, and taskbar belly-sliding.

## Supported Animations

- `idle`: Tuxedo waddle stand & tilt
- `walk`: Waddle stroll across screen
- `run`: Belly slide across window tops
- `happy`: Snowball toss celebration
- `sad`: Shiver animation
- `sleep`: Icicle nest nap
- `yawn`: Beak stretch & yawn
