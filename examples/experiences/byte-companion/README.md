# Byte the Vintage Bot 🤖

Byte is an 8-bit CRT monitor robot with ASCII facial expressions and rocket hover propulsion.

## Character Overview

- **Species:** Robot (`robot`)
- **Personality:** `friendly`
- **Category:** Retro
- **Unique Behavior:** Features ASCII screen face shifts (`^_^`, `>_<`, `zZz`), rocket hover thrust, and 8-bit synthesized sound chimes.

## Supported Animations

- `idle`: 8-bit ASCII face (`^_^`) & rocket hover
- `walk`: Gear march / rocket drift
- `run`: High-speed rocket boost
- `happy`: Pixel dance celebration (`^O^`)
- `sad`: Glitch face error (`>_<`)
- `sleep`: Low-battery standby mode (`zZz`)
- `yawn`: Gear unwind & reboot stretch
