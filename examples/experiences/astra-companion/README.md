# Astra the Stardust Dragon 🌌

Astra is a magical celestial dragon hatchling featuring stardust particle trails and automatic night-owl stargazing behaviors.

## Character Overview
- **Species:** Stardust Dragon (`stardust-dragon`)
- **Personality:** `mischievous`
- **Category:** Fantasy
- **Unique Behavior:** Generates constellation particle trails and automatically switches to stargazing mode during night hours.

## Supported Animations
- `idle`: Stardust float & wing flutter
- `walk`: Celestial glide across screen
- `run`: Star streak dash
- `happy`: Constellation bloom celebration
- `sad`: Dark cloud float
- `sleep`: Crescent moon coil sleeping mode
- `yawn`: Stardust sparkle stretch
