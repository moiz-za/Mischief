# Bramble the Mossy Hedgehog 🦔

Bramble is a woodland hedgehog with clover leaves and tiny mushrooms sprouting from its spines, curling into a cozy spiky ball when idle.

## Character Overview

- **Species:** Hedgehog (`hedgehog`)
- **Personality:** `curious`
- **Category:** Cozy
- **Unique Behavior:** Features clover leaf sprouts, woodland mushroom accents, and cozy spiky ball curling.

## Supported Animations

- `idle`: Nose wiggling & clover rustle
- `walk`: Pat-pat scurry across desktop
- `run`: Mushroom roll dash
- `happy`: Clover pop dance
- `sad`: Curled up spiky ball hiding
- `sleep`: Oak leaf nest sleeping mode
- `yawn`: Tiny hedgehog squeak yawn
