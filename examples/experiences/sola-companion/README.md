# Sola the Solar Sunflower 🌻

Sola is a smiling sun-powered sunflower in a terracotta pot that tracks time of day and reminds users to stretch, hydrate, and get sunlight.

## Character Overview
- **Species:** Sunflower (`sunflower`)
- **Personality:** `friendly`
- **Category:** Productivity
- **Unique Behavior:** Features sun-tracking petal sway, hydration reminders, and morning dew stretches.

## Supported Animations
- `idle`: Sun-facing petal sway & smile
- `walk`: Terracotta pot hop across desktop
- `run`: Fast petal sprint
- `happy`: Sunburst bloom celebration
- `sad`: Drooping wilted stem idle
- `sleep`: Folded petal night mode
- `yawn`: Morning dew stretch & yawn
