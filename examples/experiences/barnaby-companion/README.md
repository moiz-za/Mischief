# Barnaby the Coffee Capybara ☕

Barnaby is an ultra-chill capybara balancing a coffee mug and orange slice on its head.

## Character Overview

- **Species:** Capybara (`capybara`)
- **Personality:** `lazy`
- **Category:** Chill
- **Unique Behavior:** Stays completely calm, immune to chaos mode, and floats in a hot bath during prolonged idle time.

## Supported Animations

- `idle`: Ultra-chill orange balance & breathing
- `walk`: Slow, unbothered stroll across desktop
- `run`: Reluctant heavy trot
- `happy`: Hot tub orange citrus bath
- `sad`: Empty coffee mug tilt
- `sleep`: Zen sleeping mode
- `yawn`: Slow capybara yawn
