# Mochi the Shiba Baker 🍞

Mochi is a squishy bread-loaf shaped Shiba Inu wearing a baker's toque, bringing bakery aromas and cozy vibes to your desktop.

## Character Overview

- **Species:** Shiba Inu (`shiba-inu`)
- **Personality:** `lazy`
- **Category:** Cozy
- **Unique Behavior:** Features a bread-loaf body, cinnamon roll tail, and fresh croissant roll animations.

## Supported Animations

- `idle`: Loaf tilt & tail wag
- `walk`: Wobbly bread trot
- `run`: Pastry zoomies
- `happy`: Fresh croissant roll celebration
- `sad`: Flattened dough stretch
- `sleep`: Bread basket sleeping mode
- `yawn`: Flour sneeze yawn
