# Zen the Bonsai Panda 🍵

Zen is a mindful Red Panda desktop companion designed for deep work focus, Pomodoro sprints, and relaxing desktop breaks.

## Character Overview

- **Species:** Red Panda (`red-panda`)
- **Personality:** `lazy`
- **Category:** Productivity
- **Unique Behavior:** Sits calmly with a steaming tea cup, celebrates sprint completions, and provides a peaceful ambient presence.

## Supported Animations

- `idle`: Tea sipping & gentle breathing
- `walk`: Relaxed waddle across screen
- `run`: Focus sprint march
- `happy`: Flower petal celebration dance
- `sad`: Drooping ears & tilted mug
- `sleep`: Curled tail sleeping mode
- `yawn`: Warm tea steam stretch
